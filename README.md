## Why this repository?

This is more than a collection of SQL answers. It is a public record of showing up consistently, learning from mistakes, and getting better at solving problems.

- Build a strong foundation in SQL, from filtering to advanced queries.
- Practice joins, aggregation, grouping, subqueries, and window-style problem solving.
- Keep every solution organized by topic so revision stays easy.
- Track progress honestly: a problem is complete when its solution is added and understood.
